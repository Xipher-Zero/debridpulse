sgmllib3k 1.0.0
===============

Bundled notice for a runtime dependency that ships no license file inside its
distribution. Reproduced here so the shipped image still carries the upstream
licensing statement.

sgmllib3k reaches DebridPulse as a dependency of `feedparser`, which is a
dependency of the bundled Usenet acquisition service (SABnzbd). DebridPulse
does not import it.

Upstream README (verbatim)
--------------------------

    sgmllib was dropped in Python 3. For those depending on it, that's
    somewhat infortunate. This is a quick and dirty port of this old module.
    I just ran 2to3 on it and published it. I don't indend to maintain it, so
    it might be a good idea to eventually think about finding another module
    to use.

Provenance
----------

The module is a 2to3 port of the `sgmllib` module that shipped in the CPython
standard library through Python 2.7, and therefore also carries the Python
Software Foundation License (PSF-2.0) terms of that original code. The
upstream distribution declares "BSD License" without naming a variant and
packages no license text; both facts are recorded here rather than resolved by
assumption.

The full PSF-2.0 text is available at https://docs.python.org/3/license.html
