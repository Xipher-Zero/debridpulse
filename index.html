Features

Everything you need.
Nothing you don't.

Built for self-hosters who want reliable debrid downloads with full visibility into what is happening.

🖥️
Web UI
Clean single-page dashboard: all torrents, status, progress, events, file list. Dark tech aesthetic, mobile-friendly.
⏯️
Pause-aware queue
Pause individual transfers without consuming active slots. The queue advances around paused work and resumes cleanly.
🔗
Direct debrid links
Submit up to 100 hoster links in one tracked transaction, including delayed link generation and recovery.
🌐
REST API
Full REST API for adding magnets, querying status, triggering syncs and webhooks. Swagger UI at /docs.
⬇️
aria2 integration
Slot-based queue with configurable concurrency. Existing downloads detected on restart — no duplicates, no orphans.
🔔
Discord webhooks
Rich embeds for every event. Separate channel support for added vs completed. Custom avatar and username.
⚡
Live application pulse
Server-Sent Events keep transfer state, progress, and recent activity current without full-page polling.
🚫
File filters
Block by extension, keyword or minimum size. All-blocked torrents auto-removed from AllDebrid. Partial downloads continue normally.
🗄️
SQLite / WAL
A single SQLite/WAL database is the authoritative runtime store — persistent, self-contained, and zero-config.
📊
Statistics
Rolling snapshots with configurable retention. Periodic summary reports via webhook.
💾
Automatic backups
SQLite backups on a configurable schedule. Retained by number of days, stored in the data folder.
🔧
Config validation
Settings validated and auto-corrected on every startup. Invalid URLs cleared, numeric fields clamped, stale JSON reset.
Get started

Up in 60 seconds.

One compose file. Configure the rest in the browser.

1
Copy the compose file

Adjust volume paths for your setup. The download folder must match your aria2 download path.

2
Open the Web UI

http://your-server:8080 → Settings → enter your AllDebrid API key and aria2 RPC URL → Save.

3
Add your first magnet

Paste one or more direct links or magnets, or upload a .torrent file from the Dashboard.

4
Unraid App Store

Use the fork's versioned GHCR image and preserve the existing config, data and download mounts.

docker-compose.yml 
services:
  debridpulse:
    image: ghcr.io/xipher-zero/debridpulse:v1.0.11rc1
    container_name: debridpulse
    restart: unless-stopped
    ports: ["8080:8080"]
    environment:
      - TZ=Europe/Berlin
      - LOG_LEVEL=INFO
    volumes:
      - /mnt/appdata/debridpulse/config:/app/config
      - /mnt/appdata/debridpulse/data:/app/data
      - /mnt/downloads/debridpulse:/download
docker run (one-liner) 
docker run -d \
  --name debridpulse \
  --restart unless-stopped \
  -p 8080:8080 \
  -e TZ=Europe/Berlin \
  -e CONFIG_PATH=/app/config/config.json \
  -e DB_PATH=/app/data/debridpulse.db \
  -v /mnt/appdata/debridpulse/config:/app/config \
  -v /mnt/appdata/debridpulse/data:/app/data \
  -v /mnt/downloads/debridpulse:/download \
  ghcr.io/xipher-zero/debridpulse:v1.0.11rc1

Why DebridPulse

Built for reliability.

Designed to run unattended for weeks. Every edge case is handled.

What it handles automatically

  • Duplicate download prevention across restarts
  • Stuck download detection and cleanup
  • aria2 GID tracking — no orphaned jobs on restart
  • AllDebrid magnet auto-deleted after completion
  • All-filtered torrents → complete, not error
  • Config auto-corrected at startup
  • Rate-limit aware AllDebrid API calls
  • Expired debrid links regenerated during recovery

Stack

  • Python 3.12 + FastAPI — fully async
  • Single-file vanilla JS frontend (no build step)
  • aiohttp, aiosqlite, asyncpg
  • SQLite default, PostgreSQL optional
  • Single-container deployment with bundled aria2
  • GPL-2.0-or-later, 100 % open source
  • Automated tests and container smoke checks in CI
